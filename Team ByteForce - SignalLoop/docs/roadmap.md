# Development Roadmap

Suggested sequence; priorities may change after user testing and hackathon requirements are confirmed.

## Phase 1 — Foundation
- [ ] Confirm MVP requirements and user roles
- [ ] Set up GitHub repository and contribution conventions
- [ ] Create frontend project and design tokens
- [ ] Build responsive navigation and reusable components
- [ ] Add accessible loading, empty, error, and success states

## Phase 2 — Reporter Workflow
- [ ] Implement authentication
- [ ] Build student/staff home screen
- [ ] Build incident report form and validation
- [ ] Implement report submission and confirmation
- [ ] Implement report list, details, and status history

## Phase 3 — Admin and Maintenance
- [ ] Build admin incident queue
- [ ] Implement triage and assignment
- [ ] Build maintenance work queue
- [ ] Implement progress and resolution updates
- [ ] Add audit trail for important changes

## Phase 4 — AI Assistance
- [ ] Add category and summary suggestions
- [ ] Add priority and department suggestions
- [ ] Add possible duplicate suggestions
- [ ] Add optional voice-to-text
- [ ] Add manual fallback and human review

## Phase 5 — Quality and Release
- [ ] Test role permissions and data access
- [ ] Test mobile, tablet, and desktop layouts
- [ ] Conduct accessibility checks
- [ ] Test error handling and network failures
- [ ] Configure deployment and environment variables
- [ ] Add fictional or anonymized demo data
- [ ] Document known limitations and release status
